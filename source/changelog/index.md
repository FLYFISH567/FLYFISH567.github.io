记录小站一点点变好的过程。

## 2026.11.12 · 飞鱼标志与站内体验

- 页眉和开屏换上向右上飞的飞鱼标志，三圈水纹从标志周围依次扩散。修复首次打开时正文先闪现、开屏随后盖住页面的问题。
- [每日看板](/briefing/)先展示 12 条新闻，再加载完整列表。刷新时保留正在浏览的新闻链接或按钮的键盘焦点。
- 压缩关于页的[旅行地图](/about/#footprints-title)，保留地图轮廓和缩放交互。移动端在脚本加载失败时也能直接打开主导航链接。
- 为主要栏目补上各自的页面描述，分享链接时可使用首页天空照片作为封面。
- 「今日一句」整理为 360 条，加入更多作者和作品，按作者错开国内外摘句。
- [每日看板](/briefing/)移除已读和未读状态，「我的收藏」独立于资讯订阅，可单独搜索。
- [音乐馆](/music/)可按歌名或歌手筛选当前歌单，保留正在播放的歌曲和进度。
- [工具箱](/toolbox/#toolbox-local)在本页保留各工具的输入和结果，时间戳转换会指出无效日期，并支持指定时区。
- [相册](/album/)返回时可恢复原分类，灯箱能复制单张照片链接。旅行相册可回到对应的地图点位，[说说](/essay/)也有了单条链接。
- [追番列表](/bangumis/)可按作品名称搜索，筛选状态可以通过链接分享。
- [留言板](/comments/)新增直达 GitHub 留言串的入口，邮件联系移到页头。404 页可以直接前往文章搜索。
- [文章归档](/archives/)按月份和页码显示对应文章，分类与标签有各自的目录。从文章库读完返回时，会恢复原来的筛选和位置。修复了一条旧站内链接，并为正文图片放大补上键盘入口。
- [书影音](/shelf/)补上四部作品的简介和出处，[关于页](/about/#now-title)更新了小站近况。

## 2026.10.31–11.01 · 四季风景与小鱼

- 为春夏秋冬加上各自的树景，花瓣、流萤、落叶和雪花会随微风与阵风改变飘动方向。
- 调整不同季节的风势和粒子响应，小鱼吐泡泡时会留下一串渐渐散开的气泡。

## 2026.10.30 · 互动与细节

- 解耦无刷新导航与歌单加载，复用预取请求，按页面加载专用模块。
- 留言板加入顶部导航；明暗切换增加圆形扩散动画。
- 四季氛围设置移到页脚，加入花瓣、流萤、落叶和雪花。
- 灵感扭蛋扩充为 128 条，整轮抽完前不重复；每日一句去掉容易误读的日期标记。
- 为小鱼增加错开的随机动作，新增灵感扭蛋和 404 寻路小游戏。
- 书影音分类支持筛选；每日一句扩充至 365 条。
- 优化长英文标题，并加入可选的季节昼夜氛围。
- 校订每日一句的原文和出处，优化评论区跨页加载，修复表情选择面板在窄屏上被截断的问题。
- 工具箱加入 24hBook，入口直接打开网站首页。

## 2026.10.29 · 逛逛与交流

- 增加常用网站导航和可按需展开的小工具。
- 接入基于 GitHub Discussions 的文章评论和留言页。
- 添加书影音收藏馆，让电影和书籍有了自己的位置。
- 调整关于页与首页侧栏，加入今日一句和小鱼互动。
- 为常用页面加入有限预取，减少等待。

## 2026.10.28 · 每日看板

- 上线每日看板，整理新闻来源与环球市场。
- 增加来源订阅、阅读状态和行情自选。

这些记录以实际更新为准，不随每次构建自动变化。
