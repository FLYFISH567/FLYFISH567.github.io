# 准备事项

1. 修改个人信息
2. 绑定学校邮箱

点击[settings/profile](https://github.com/settings/profile)进入设置-个人介绍页面

如图修改个人信息和绑定学校邮箱，主包自己搞只做了这两步


![image-20260406205005019](https://flyfish567.oss-cn-shenzhen.aliyuncs.com/web.imgimage-20260406205005019.png)

邮箱绑定完成之后显示如下

![image-20260406205022754](https://flyfish567.oss-cn-shenzhen.aliyuncs.com/web.imgimage-20260406205022754.png)

3. <font style="color:rgb(77, 77, 77);">双因素身份认证</font>

<font style="color:rgb(77, 77, 77);">打开</font>[<font style="color:rgb(78, 161, 219);">GitHub</font>](https://github.com/settings/profile)<font style="color:rgb(77, 77, 77);">——点击头像——Settings——Password and authentication，添加双重身份认证</font>

![image-20260406205046586](https://flyfish567.oss-cn-shenzhen.aliyuncs.com/web.imgimage-20260406205046586.png)

![image-20260406205120720](https://flyfish567.oss-cn-shenzhen.aliyuncs.com/web.imgimage-20260406205120720.png)

**解决方法：**

<font style="color:rgb(77, 77, 77);">  ① 选取 </font>**<font style="color:rgb(77, 77, 77);">Authenticator </font>**<font style="color:rgb(77, 77, 77);">认证器应用认证方式：直接在 应用商店里搜索下载 Authenticator 应用，之后打开扫描 GitHub 上的 QR码 进行账户绑定输入对应的密钥即可；</font>

<font style="color:rgb(77, 77, 77);">如下图表示验证成功：</font>
![image-20260406205404559](https://flyfish567.oss-cn-shenzhen.aliyuncs.com/web.imgimage-20260406205404559.png)

# 进入认证页面

学生认证网址：[GithubEducation](https://github.com/education)

当然也可以直接点击这个：[学生优惠](https://github.com/settings/education/benefits?locale=en-US)
![image-20260406205345992](https://flyfish567.oss-cn-shenzhen.aliyuncs.com/web.imgimage-20260406205345992.png)

点击 开始认证


![image-20260406205259458](https://flyfish567.oss-cn-shenzhen.aliyuncs.com/web.imgimage-20260406205259458.png)

<font style="color:rgb(77, 77, 77);">选择Student——直接点击Select this school（没有的话就在搜索框里搜索学校英文名字）——然后选择前面验证好的学校邮箱——之后点击Share Location</font>**<font style="color:rgb(77, 77, 77);">（这里如果浏览器跳出来是否允许访问位置的话一定要点允许！！！）</font>**


![image-20260406205237395](https://flyfish567.oss-cn-shenzhen.aliyuncs.com/web.imgimage-20260406205237395.png)

<font style="color:rgb(77, 77, 77);">这里选择第一个Dated school ID，然后把学生卡/学生证拍一下提交即可</font>

![image-20260406205206574](https://flyfish567.oss-cn-shenzhen.aliyuncs.com/web.imgimage-20260406205206574.png)

<font style="color:rgb(77, 77, 77);"> 提交申请，主包周末半小时不到就通过了，希望大家也可以通过。</font>
![image-20260406205153868](https://flyfish567.oss-cn-shenzhen.aliyuncs.com/web.imgimage-20260406205153868.png)
